# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please email us privately rather than using the public issue tracker.

**Please do not open public issues for security vulnerabilities.**

### How to Report

1. Send an email to the repository maintainer with details of the vulnerability
2. Include steps to reproduce (if applicable)
3. Allow time for a response before public disclosure

### What to Include

- Description of the vulnerability
- Location in the code (file, function, line number)
- Steps to reproduce the issue
- Potential impact
- Suggested fix (if you have one)

## Security Considerations

This repository contains educational algorithm and problem-solving solutions. 

### Scope

- Bug reports related to code correctness
- Performance issues that could cause resource exhaustion
- Issues with educational material accuracy

### Out of Scope

- Educational code is not intended for production use
- These solutions are for learning purposes only
- Do not use algorithm implementations from this repo in production without security review

## Supported Versions

## Security Best Practices

1. **Do not use this code in production** without thorough security review
2. **Understand the algorithms** before implementation
3. **Test thoroughly** with edge cases
4. **Keep dependencies updated** if you extend this project
