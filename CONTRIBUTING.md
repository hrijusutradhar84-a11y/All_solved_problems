# Contributing Guidelines

Thank you for your interest in contributing to **All_solved_problems**! This guide will help you get started.

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Focus on the ideas, not the person
- Help others learn

## How to Contribute

### 1. Submitting New Solutions

- Check if a solution already exists for this problem
- Ensure your solution is well-documented
- Include complexity analysis
