# All Solved Problems

A comprehensive collection of algorithmic and programming problem solutions organized by category.

## Directory Structure

\\\
All_solved_problems/
├── array/                    # Array manipulation problems
├── string/                   # String processing problems
├── dynamic_programming/      # DP optimization problems
├── graph/                    # Graph theory and traversal
├── tree/                     # Tree structures and algorithms
├── recursion/                # Recursive solutions
├── sorting/                  # Sorting algorithms
├── searching/                # Search algorithms
├── math/                     # Mathematical problems
├── utils/                    # Helper functions and utilities
└── README.md
\\\

## Categories

- **array/** - Two pointers, sliding window, subarray problems
- **string/** - Pattern matching, manipulation, parsing
- **dynamic_programming/** - Optimization, memoization, tabulation
- **graph/** - BFS, DFS, shortest path, connectivity
- **tree/** - Traversals, BST, balanced trees
- **recursion/** - Backtracking, divide and conquer
- **sorting/** - Custom sorting, merging, partitioning
- **searching/** - Binary search, variants
- **math/** - Number theory, combinatorics
- **utils/** - Common utilities and helpers

## How to Use

Each problem solution is contained in a .py file with:
- Problem description as docstring
- Solution implementation
- Example usage
- Time and space complexity notes

## Getting Started

1. Navigate to a category folder
2. Open a .py file to see the solution
3. Read the docstring for problem details
4. Review the implementation and complexity analysis
